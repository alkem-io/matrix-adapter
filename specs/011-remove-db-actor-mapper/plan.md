# Implementation Plan: Remove DB Actor ID Mapper

**Branch**: `011-remove-db-actor-mapper` | **Date**: 2026-03-07 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/011-remove-db-actor-mapper/spec.md`

## Summary

Remove the temporary database-based Actor ID Mapper introduced in 009-db-actor-id-mapper. The adapter should always use direct ID mapping (actor UUID = Matrix localpart). This involves removing the alkemiodb infrastructure package, database configuration, ActorResolver interface and conditional logic in IDMapper, pgx/v5 dependency, and updating documentation.
